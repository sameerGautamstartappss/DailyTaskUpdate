## 📋 Topics Covered

### 1. Database Fundamentals
- [x] **Definition of RDBMS**
  - Understanding what RDBMS is and its importance
  - Comparison with other database systems

- [x] **Key Features of RDBMS (ACID Properties)**
  - **Atomicity**: All-or-nothing transaction execution
  - **Consistency**: Database integrity maintenance
  - **Isolation**: Concurrent transaction handling
  - **Durability**: Permanent transaction commits

- [x] **Types of Database Models**
  - **Hierarchical Model**: Tree-like structure with parent-child relationships
  - **Network Model**: Graph structure allowing multiple parent-child relationships
  - **Relational Model**: Table-based structure with relationships via keys

### 2. Relational Database Core Concepts
- [x] **Relational Database Concepts**
  - **Tables**: Primary data storage structures
  - **Rows (Records)**: Individual data entries
  - **Columns (Fields)**: Data attributes/properties

- [x] **Data Integrity Constraints**
  - **Primary Key**: Unique identifier for table records
  - **Foreign Key**: Links between related tables
  - **Unique Constraint**: Ensures column value uniqueness
  - **Not Null**: Prevents empty values in critical fields

### 3. Data Definition Language (DDL)
- [x] **CREATE**: Building database structures
  - Creating databases, tables, indexes
  - Defining column data types and constraints

- [x] **ALTER**: Modifying existing structures
  - Adding/dropping columns
  - Modifying column properties
  - Adding/removing constraints

- [x] **DROP**: Removing database objects
  - Dropping tables, databases, indexes
  - Understanding cascading effects

### 4. Data Manipulation Language (DML)
- [x] **Basic CRUD Operations**
  - **SELECT**: Retrieving data from tables
  - **INSERT**: Adding new records
  - **UPDATE**: Modifying existing records
  - **DELETE**: Removing records

### 5. Advanced SELECT Operations
- [x] **SELECT Statements (Retrieving Data)**
  - Basic syntax and structure
  - Single and multiple table queries

- [x] **WHERE Clause (Filtering Records)**
  - Conditional data retrieval
  - Comparison operators (=, >, <, >=, <=, <>)

- [x] **ORDER BY Clause (Sorting)**
  - Ascending (ASC) and Descending (DESC) sorting
  - Multi-column sorting

- [x] **DISTINCT (Removing Duplicates)**
  - Retrieving unique values
  - Performance considerations

- [x] **SELECT with Multiple Columns**
  - Column selection strategies
  - Using aliases for readability

### 6. Aggregate Functions & Grouping
- [x] **Aggregate Functions**
  - **COUNT()**: Counting records
  - **AVG()**: Calculating averages
  - **SUM()**: Total calculations
  - **MIN()**: Finding minimum values
  - **MAX()**: Finding maximum values

- [x] **GROUP BY Clause**
  - Grouping data based on conditions
  - Creating summary reports
  - Working with multiple grouping columns

- [x] **HAVING Clause**
  - Filtering grouped data
  - Difference between WHERE and HAVING
  - Using aggregate functions in conditions

### 7. Advanced Query Techniques
- [x] **Subqueries (Nested Queries)**
  - Inner queries within outer queries
  - Correlated vs non-correlated subqueries
  - Using subqueries in SELECT, WHERE, and FROM clauses

- [x] **Advanced Operators**
  - **IN**: Matching values in a list
  - **BETWEEN**: Range-based filtering
  - **LIKE**: Pattern matching with wildcards
  - **NOT LIKE**: Negative pattern matching
